# D'CRUNCHY WEBSITE

Website profil usaha D'Crunchy.

## Isi folder

- `index.html` = isi/struktur website
- `styles.css` = warna, ukuran, layout, dan tampilan
- `script.js` = interaksi sederhana
- `images/` = tempat foto produk

## Cara membuka di VS Code

1. Buka VS Code.
2. Pilih `File > Open Folder`.
3. Pilih folder `DCRUNCHY-WEBSITE`.
4. Buka `index.html`.
5. Klik kanan di `index.html`.
6. Pilih `Open with Default Browser` jika tersedia.

Alternatif paling mudah:
- Buka folder project di File Explorer.
- Klik dua kali `index.html`.
- Website akan terbuka di Chrome.
